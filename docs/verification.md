# 검증 기록

검증일: 2026-11-15 (KST)

## 최신 결과

- 로컬 환경: macOS, Node.js 24.7.0, npm 11.5.1.
- 지원 버전 설정: Node.js 22 이상. `.nvmrc`는 24.
- API 자동 테스트 **36개**, 프론트 자동 테스트 **13개**, 합계 **49개 통과**.
- API TypeScript 빌드, Vue 타입 검사, Vite 프로덕션 빌드 통과.
- 코드 포맷 검사 통과.
- 최종 독립 설치본에서 `npm audit` 결과 알려진 취약점 0건. 이후 공시 상태는 달라질 수 있음.

## 실행 환경 재현

1. node_modules/dist/data를 제외한 별도 복사본 생성.
2. npm 캐시를 사용한 `npm ci --offline` 성공.
3. 당시 전체 테스트 46개 및 API/Vue 빌드 통과.
4. 이후 시간 표시 보완과 1개 테스트 추가는 작업본에서 프론트 12개 및 빌드로 확인.
5. 별도 포트에서 `npm start` 실행, Vue HTML과 API 응답 확인.
6. 프로세스 종료·재시작 후 삭제 상태/신청 취소/이력 5건/시각 정밀도 유지 확인.

## 실제 브라우저

독립 설치본에서 가상 검증 데이터를 생성해 다음을 확인했습니다.

- 학생 생성·이름 수정·삭제.
- 초·밀리초 운영 기간의 자습실 생성과 최대 인원 수정.
- 방문 신청, 내 신청 조회, 시간 변경, 취소, 정원 복원, 재신청.
- 강사 상세의 신청·변경·취소·재신청 이력.
- 자습실 삭제 후 목록 제외와 기존 신청 자동 취소.
- 삭제된 학생이 선택된 상태에서 유효 학생으로 자동 전환.
- 모달 표시 중 배경 탐색 차단.
- 브라우저 콘솔 오류 없음.

## 검증 범위의 한계

- 실제 운영 부하, 다중 프로세스 공유 저장, 타 운영체제 검증은 수행하지 않음.
- 브라우저 검증은 직접 조작이며 자동 브라우저 회귀 스크립트를 포함하지 않음. 프론트 상태/시간 처리는 자동 회귀 테스트 포함.
- GitHub Actions의 Node.js 22/24 검증 통과. [실행 결과](https://github.com/hyo-max/study-room/actions/runs/43717770685).
- 로그인 생략 데모이므로 실제 계정 인증 보안 검증 대상이 아님.

상세한 원문 대조 및 수정 전후 내용은 [요구사항 점검 보고서](requirements-audit.md)를 참고하세요.

- 학생 입장 후 학생 메뉴와 본인 신청 표시. 내부의 강사/학생 전환 버튼 0개 확인.
- 나가기 후 선택 초기화, 강사 재입장 후 강사 메뉴 표시 확인.
- 브라우저 콘솔 오류 없음. Vue 타입 검사와 프로덕션 빌드 통과.
- 실제 로그인 인증을 추가한 것은 아님. 과제에서 허용한 역할 선택의 사용자 흐름만 분리.

## 최종 제출 ZIP 재검증

- 제출 ZIP의 파일 36개가 작업본과 바이트 단위로 일치하는지 확인하고 새 폴더에 압축 해제.
- node_modules/dist/data가 없는 상태에서 캐시 기반 `npm ci --offline` 성공.
- 압축 해제본에서 API 35개 + 프론트 12개, 총 47개 테스트 통과.
- API 빌드, Vue 타입 검사, Vite 빌드, 전체 포맷 검사 통과.
- 압축 해제본의 프로덕션 서버를 3102 포트로 실행하여 HTML, JavaScript 정적 파일, 자습실 API의 HTTP 200 응답 확인 후 종료.
- 검증 기록 갱신 후 ZIP 재생성. 기능 코드는 변경하지 않음.

## 컴포넌트·타입 리팩터링 후 확인

- App.vue 955줄 → 198줄. 6개 컴포넌트로 화면 책임 분리.
- 소스·테스트의 명시적 any 제거. 역할/페이지 유니온, HTTP 헤더, 요청 검증 결과, 컴포넌트 props/emit 타입 명시.
- JSON 객체가 아닌 입력 거절과 비정형 오류 응답 처리 회귀 테스트 2개 추가. 총 49개 테스트 통과.
- API 빌드, Vue 타입 검사 및 빌드, 전체 포맷 검사 통과.
- 독립 데이터 파일과 3103 포트에서 실제 브라우저로 학생 생성/수정/검색, 자습실 생성/수정/상세, 신청/시간 변경/취소/재신청, 이력 4건, 활성 신청 학생 삭제 거절, 자습실 삭제 후 자동 취소 및 학생 삭제 성공 확인.
- 초·밀리초 입력과 표시 유지. 콘솔 warning/error 없음. 기존 개발 데이터는 변경하지 않음.
- 갱신된 제출 ZIP(43개 파일)을 새 폴더에 풀어 캐시 기반 독립 설치 후 49개 테스트·전체 빌드·포맷 검사 재통과. 최종 검증 기록만 추가 후 재포장.
